## ✨ Features

- **Responsive Design** — Fully optimized layout across desktop, tablet, and mobile (including a dedicated mobile navigation menu with hamburger toggle)
- **Smooth Scroll Navigation** — Section-based navigation (Home, About, Skills, Education, Projects, GitHub, Contact)
- **Dynamic Hero Section** — Introduction with profile photo, key stats (projects built, DSA solved, technologies), and quick links to resume/projects
- **About Section** — Personal summary, location, and core tech tags
- **Education Timeline** — Degree and institution details with clean card UI
- **Skills Showcase** — Categorized into Backend, Frontend, Database, DevOps & Tools, and Cloud & AI
- **Project Cards** — Highlighted projects with tech stack tags and direct GitHub links
- **GitHub Portfolio Section** — Quick access to full GitHub profile
- **Contact Section** — Email, LinkedIn, location, availability status, and a WhatsApp quick-connect button
- **Social Integration** — LinkedIn, GitHub, LeetCode, and Email links throughout
- **Downloadable Resume** — One-click resume access via Google Drive link

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ArpitTyagi0001/portfolio.git

# Navigate into the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173` (or `http://localhost:3000` depending on your setup).

### Build for Production

```bash
npm run build
```
